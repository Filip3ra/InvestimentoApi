# 💹 Investment API
Essa API simula quanto tempo levaria pra você atingir os primeiros R$ 100.000,00 através de investimentos mensais e anuais.


## 💰 Como funciona?
A ideia é simular uma situação onde você invista todo mês em algum investimento atrelado ao CDI (que deixei fixo em 14,15%), 
tipo um CDB que rende 100%. Caso você tenha uma patrimônio inicial, ele será investido em alguma aplicação que renda X% ao ano. 
Ao final do ano esse patrimônio será somado com seu investimento mensal, se tornando seu novo patrimônio, repetindo esse ciclo até atingir seu valor objetivo. 

## 📈 E a inflação?
Sim, a inflação está sendo considerada e você pode ajustar ela, mas a média nos últimos vinte e tantos anos ficou em torno de 5%, 
deixei alguns valores sugeridos automaticamente.
